🚚 SwiftRoute Logistics Dashboard (Power BI Project)

📌 Project Overview
This project focuses on analyzing logistics operations for a delivery-based company to identify performance gaps and improve operational efficiency.
The dashboard provides real-time insights into orders, delivery performance, drivers, hubs, and vehicle utilization.


🎯 Objective

The goal of this project is to:

1. Monitor delivery performance and operational KPIs
2. Identify causes of delivery delays
3. Analyze driver efficiency and hub capacity
4. Optimize vehicle utilization and logistics planning


📊 Key Metrics (KPIs)

Total Orders: 27979
On-Time Delivery Rate: 79.60%
Customer Satisfaction (CSAT): 84.4%
Average Delivery Time: 35.78 hours

🧩 Dashboard Features

1️⃣ Overview Dashboard

1. Orders vs Hub Capacity analysis
2. Hub performance ranking
3. Driver performance (Experience vs Rating)
4. Vehicle utilization (Active vs Maintenance)

2️⃣ Drivers Analysis
1. Driver-wise delivery performance
2. Drivers with highest delays
3. Experience vs performance correlation
4. Individual driver deep-dive (profile, deliveries, trend)
  
3️⃣ Vehicle Analysis
1. Active vs Maintenance vehicles
2. Orders by vehicle type (Van, Truck, Pickup, Box Truck)
3. Vehicle model performance
4. Vehicle age vs breakdown analysis


🛠️ Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling (Star Schema)
- Data Visualization


📈 Key Insights

🚨 On-time delivery rate is below optimal (~79%), indicating operational inefficiencies
📍 Certain hubs (like EI Paso Hub & Houston Hub) perform better than others
🚗 Majority of deliveries are handled by Vans (~62%), indicating heavy dependency
👨‍✈️ Some drivers contribute disproportionately to delays → scope for training/improvement
⏱️ Higher delivery times are impacting customer satisfaction


⚡ Challenges Faced
- Handling multiple datasets (Drivers, Orders, Vehicles, Hubs)
- Building relationships and data model
- Creating dynamic measures (KPIs, comparisons vs previous month)
- Designing an intuitive and interactive UI


🚀 Business Impact

This dashboard helps stakeholders:

- Improve delivery efficiency
- Optimize resource allocation (drivers & vehicles)
- Reduce delays and increase customer satisfaction
- Make data-driven logistics decisions
